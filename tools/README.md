Portable renderers, not committed. On Windows unzip a Graphviz release to
`tools/graphviz/` (so that `tools/graphviz/bin/dot.exe` exists) and put
`plantuml.jar` here. On Linux install them instead:

    sudo apt install graphviz plantuml default-jre

If neither is present, `dot` and `plantuml` are expected on PATH.
